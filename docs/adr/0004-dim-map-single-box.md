# The dim base layer is the full diatonic map; only the active box is highlighted

Rather than tinting each of the seven boxes its own colour, we render every scale
note across the neck dimmed and light up only the active box over it. Because the
seven boxes tile the neck completely, the dim layer _is_ the full scale map — this
matches the reference diagram the user practices from and avoids untangling the heavy
note-sharing between adjacent boxes.
