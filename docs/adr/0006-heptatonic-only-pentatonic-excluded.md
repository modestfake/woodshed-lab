# The box engine supports any 7-note scale; pentatonic is deliberately excluded

The engine is scale-driven: major, natural/harmonic/melodic minor, and the diatonic
modes are all just heptatonic offset sets fed to the same 3NPS box generator.
Pentatonic scales have five notes and break the "three notes per string" invariant
the box system depends on, so they are intentionally out of scope here and remain a
separate curriculum item. The explicit "no" is the point — don't try to force
pentatonic through the box generator.
